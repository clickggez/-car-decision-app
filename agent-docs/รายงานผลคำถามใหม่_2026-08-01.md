# รายงานผลการทดลอง — แบบสอบถามชุดใหม่ (คำถามเพิ่ม 10 ข้อ)

**วันที่:** 2026-08-01
**ข้อมูล:** n=500 (ไฟล์ `เน้น ice(500) 1.csv`) — แบบสอบถามเดิม + คำถามใหม่ 10 ข้อต่อท้าย
**เงื่อนไข:** ไม่แก้คำถามเดิม (เพิ่มต่อท้ายเท่านั้น) ตามที่อาจารย์อนุญาต
**เป้าหมายที่อาจารย์ตั้งไว้:** held-out test accuracy > 80% ทั้ง BUY และ FUEL

---

## 1. สรุปผลหลัก

| โมเดล | ผลเดิม (n=715, ไม่มีคำถามใหม่) | **ผลใหม่ (n=500, มีคำถามใหม่)** | baseline\* | lift เทียบ baseline |
|---|---|---|---|---|
| **BUY** (ซื้อ / ไม่ซื้อ) | 65.0% | **68.5% ± 4.1%** | 58.4% | **+10.1 จุด** ✔ |
| **FUEL** (EV / Hybrid / ICE) | 48.7% | **44.3% ± 6.1%** | 53.2% | **−8.9 จุด** ✘ |

\* baseline = ทายคลาสที่มีมากที่สุดเสมอ โดยไม่ใช้โมเดลเลย
ตัวเลขทุกช่องวัดจาก **20 random splits** (`StratifiedShuffleSplit`, test_size=0.2) ไม่ใช่ split เดียว
เพื่อลดความผันผวน — ไม่มีการเลือก seed ที่ให้ผลดีที่สุด

**ไม่ถึงเป้า 80% ทั้งสองโมเดล**

---

## 2. คำถามใหม่ 10 ข้อช่วยหรือไม่ (Ablation — ข้อมูลชุดเดียวกัน)

เทียบบนข้อมูล n=500 ชุดเดียวกัน ต่างกันแค่ "ใส่ / ไม่ใส่" ฟีเจอร์จากคำถามใหม่

| โมเดล | ฟีเจอร์เดิมเท่านั้น | เดิม + คำถามใหม่ | ส่วนต่าง |
|---|---|---|---|
| BUY | 67.2% | 68.5% | **+1.4 จุด** |
| FUEL | 44.0% | 41.3% | **−2.7 จุด** |

**ข้อสรุป:** ส่วนต่าง +1.4 จุดของ BUY **เล็กกว่าค่าความผันผวนของการวัดเอง (±4.1 จุด)**
จึงถือว่า **ไม่มีนัยสำคัญ** — คำถามใหม่ไม่ได้ช่วยอย่างที่คาด และทำให้ FUEL แย่ลงเล็กน้อย

## 4. ทางเลือกเชิงตัวชี้วัดที่ทดสอบเพิ่ม

| ตัวชี้วัด | BUY | FUEL |
|---|---|---|
| Accuracy | 68.5% | 44.3% |
| Balanced accuracy | 66.4% | 43.3% |
| Macro F1 | 66.5% | 39.1% |
| ROC-AUC | **0.715** | 0.595 |
| Top-2 accuracy (แนะนำ 2 อันดับแรก) | — | 77.9% |

**หมายเหตุสำคัญเรื่อง Top-2:** baseline ของ top-2 (แนะนำ 2 คลาสใหญ่สุดเสมอ) = **78.5%**
โมเดลได้ 77.9% → **ยังแพ้ baseline** ตัวเลข 77.9% จึงนำไปอ้างว่า "เกือบ 80%" ไม่ได้

**หมายเหตุ:** เคยพิจารณาการยุบ EV+Hybrid เป็นคลาสเดียว (เหลือ 2 คลาส) แต่**ตัดทิ้ง**
เพราะขัดกับวัตถุประสงค์ของระบบที่ต้องแยกแนะนำรถ 3 ประเภท

## 5. ข้อสังเกตเรื่องคุณภาพข้อมูล (สำคัญ — ควรตรวจสอบก่อนเขียนเล่ม)

พบรูปแบบที่ไม่สอดคล้องกันเองภายในข้อมูล 2 จุด:

**5.1 คำตอบขัดกันเองระหว่าง Q1 กับ label ของ BUY**

| ตอบ Q1 (เจตนาซื้อ) | ตอบว่า "มีแนวโน้มซื้อ" | ตอบว่า "ยังไม่มีแนวโน้มซื้อ" |
|---|---|---|
| 7 = ตั้งใจซื้อแน่นอน | 45.5% | **54.5%** |
| 2 = แทบไม่ตั้งใจซื้อ | **70.4%** | 29.6% |

คนที่บอกว่า "ตั้งใจซื้อแน่นอนที่สุด" กลับตอบว่าไม่มีแนวโน้มซื้อ *มากกว่า* คนที่บอกว่าแทบไม่ตั้งใจซื้อ
— ความสัมพันธ์กลับทิศจากที่ควรเป็น

**5.2 ปัจจัยที่ทฤษฎีระบุชัดกลับไม่สัมพันธ์กับเป้าหมายที่ควรสัมพันธ์**

"การมีจุดชาร์จที่บ้าน/ที่ทำงาน" — งานวิจัย EV adoption ทั่วโลกระบุเป็นปัจจัยทำนายอันดับ 1
ของการเลือก EV — แต่ในข้อมูลชุดนี้ได้ p=0.950 กับ FUEL (ไม่เกี่ยวข้องเลย)
ขณะที่กลับไปสัมพันธ์กับ BUY แทน (p=0.0001) ซึ่งกลับด้านจากทฤษฎี

**ข้อเสนอ:** ควรตรวจสอบกระบวนการเก็บข้อมูล (เช่น ผู้ตอบอ่านคำถามครบหรือไม่, มีการตอบ
แบบรีบเร่ง/สุ่มหรือไม่) ก่อนนำผลไปเขียนในเล่ม เพราะหากกรรมการสอบตรวจพบความไม่สอดคล้อง
นี้เอง จะกระทบความน่าเชื่อถือมากกว่าเรื่องตัวเลข accuracy

## 6. สิ่งที่ทดลองมาแล้วทั้งหมด (สะสมทุกรอบ)

| แนวทาง | ผล |
|---|---|
| 5 อัลกอริทึม (SVM / ANN / RF / GB / XGBoost) | ต่างกันไม่เกิน ~1 จุด |
| Ensemble (soft-voting + stacking) | ไม่ดีกว่าตัวเดี่ยวอย่างมีนัยสำคัญ |
| Ordinal encoding แทน One-Hot | ผลใกล้เคียงเดิม |
| Composite / interaction features | ผ่านเกณฑ์บางตัว แต่ไม่เปลี่ยนผลรวม |
| Mutual Information + permutation test | ไม่มีฟีเจอร์ผ่าน threshold (FUEL) |
| เพิ่ม n (225 → 505 → 715 → ชุดใหม่ 500) | BUY ดีขึ้นถึงจุดหนึ่งแล้วอิ่มตัว, FUEL ไม่ขยับ |
| ปรับ alpha / force_keep ของ feature selection | ทดสอบจนอิ่มตัว |
| **คำถามใหม่ 10 ข้อ (TPB + EV adoption)** | **+1.4 จุด (ไม่มีนัยสำคัญ), FUEL −2.7 จุด** |
| **ตัวชี้วัดทางเลือก (balanced acc / AUC / top-2)** | **ไม่มีตัวใดถึง 80% แบบที่อ้างอิงได้** |

## 7. ข้อสรุปและข้อเสนอเพื่อหารือกับอาจารย์

1. **เป้า 80% ไม่สามารถบรรลุได้จากข้อมูลชุดนี้** ด้วยวิธีการที่ถูกต้องตามระเบียบวิธีวิจัย
   — ยืนยันด้วยการทดลองครบทุกมิติ (อัลกอริทึม / การเข้ารหัส / ฟีเจอร์ / จำนวนตัวอย่าง /
   คำถามใหม่ / ตัวชี้วัด)

2. **BUY model มีคุณค่าเชิงประจักษ์จริง** — 68.5% เทียบ baseline 58.4% คือ **ทำได้ดีกว่า
   การเดา 10.1 จุด** และ ROC-AUC 0.715 (สูงกว่า 0.5 ของการเดาสุ่มอย่างชัดเจน)
   → เสนอให้รายงานเป็น **"baseline lift"** แทน accuracy ตายตัว

3. **FUEL model ไม่มีอำนาจการทำนาย** — ต่ำกว่า baseline 8.9 จุด และแม้วัดแบบ top-2
   ก็ยังแพ้ baseline → ควรพิจารณาว่านี่คือ **ผลการวิจัย (finding)** ว่าตัวแปรใน
   แบบสอบถามชุดนี้ไม่สามารถทำนายการเลือกประเภทเชื้อเพลิงได้ ไม่ใช่ความล้มเหลวของโมเดล

4. **ทางเลือกที่เหลือ** หากอาจารย์ยืนยันเป้า 80%:
   - ออกแบบแบบสอบถามใหม่ทั้งฉบับ (ไม่ใช่เพิ่มต่อท้าย) พร้อม pilot test ตรวจ variance
     และตรวจความสอดคล้องภายในของคำตอบก่อนเก็บเต็มรอบ
   - หรือเปลี่ยนนิยามของปัญหา/ตัวชี้วัดตามข้อ 2-3
