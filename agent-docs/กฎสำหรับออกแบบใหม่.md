# กฎสำหรับออกแบบหน้าเว็บ CarDSS ใหม่

> สำหรับส่งให้ AI/นักออกแบบที่ช่วยออกแบบ (29 ก.ย. 2569)
> **สไตล์ Tesla เดิมยกเลิกแล้ว** ออกแบบใหม่ได้ทั้งหมด ยกเว้นข้อห้ามข้างล่าง

## 1. เว็บนี้คืออะไร
- ระบบช่วยตัดสินใจซื้อรถยนต์ตามประเภทเชื้อเพลิง (โครงงานปริญญา)
- **ผู้ใช้หลัก:** คนไทยทั่วไปที่กำลังคิดซื้อรถ หลายคนอ่านภาษาอังกฤษไม่ออก ใช้มือถือกับคอมพิวเตอร์พอ ๆ กัน
- **ผู้ใช้รอง:** กรรมการสอบ ซึ่งจะตรวจว่าตัวเลขทุกตัวบนหน้าเว็บจริงและตรวจสอบได้
- **เป้าหมาย:** ผู้ใช้ได้คำแนะนำว่าควรดูรถแบบไหน และรู้ด้วยว่าเชื่อผลนั้นได้แค่ไหน

## 2. ห้ามเปลี่ยนเด็ดขาด

### คำถามในฟอร์ม ต้องตรงกับโมเดลทุกข้อ
คำถามต้องครบตามนี้ ห้ามเพิ่ม ห้ามลด ห้ามเปลี่ยนตัวเลือก ส่วนการจัดวาง ลำดับ และหน้าตาเปลี่ยนได้

**ฟอร์ม BUY ("จะซื้อรถไหม") มี 10 ข้อ**

| คำถาม | ตัวเลือก |
|---|---|
| อายุ | 20–23 / 24–26 / 27–30 / 31–40 / 41–50 / 51–60 / 60 ปีขึ้นไป |
| อาชีพ | นักศึกษา / พนักงานบริษัทเอกชน / ข้าราชการ / รัฐวิสาหกิจ / เจ้าของกิจการ / ค้าขาย / อาชีพอิสระ / ชาวประมง-เกษตรกร / อื่น ๆ |
| ระดับการศึกษา | ต่ำกว่า ม.3 / ม.3 / ม.6 / ปวช.-ปวส. / ปริญญาตรี / ปริญญาโท / ปริญญาเอก |
| จำนวนสมาชิกในครอบครัว (รวมตัวเอง) | 1–2 / 3–4 / 5 คนขึ้นไป |
| จำนวนบุตร | ไม่มี / 1 / 2 / 3 / มากกว่า 3 |
| ลักษณะที่พักอาศัย | บ้านเดี่ยว / ทาวน์โฮม / คอนโด-อพาร์ตเมนต์ / หอพัก |
| พื้นที่จอดรถ | มีที่จอดส่วนตัว / ส่วนกลาง / ไม่มี |
| งบประมาณซื้อรถ | ต่ำกว่า 5 แสน / 5–8 แสน / 8 แสน–1.2 ล้าน / 1.2–1.5 ล้าน / 1.5 ล้านขึ้นไป |
| วัตถุประสงค์ (เลือกได้หลายข้อ อย่างน้อย 1) | เดินทางไปทำงาน-เรียน / ค้าขาย-ธุรกิจ / ท่องเที่ยว / ความสะดวกในการเดินทาง / หลีกเลี่ยงปัญหาขนส่งมวลชน |
| ข้อกังวล (เลือกได้หลายข้อ **ไม่บังคับ** คนยังไม่มีรถข้ามได้) | ราคาน้ำมัน / ค่าไฟฟ้า / ปั๊มน้ำมัน-สถานีชาร์จ / ศูนย์บริการและอะไหล่ / อายุการใช้งาน / ค่าใช้จ่ายในการซ่อมบำรุง / มูลค่าการขายต่อ |

**ฟอร์ม FUEL ("เหมาะกับรถแบบไหน") มี 6 ข้อ** ตอบได้เฉพาะคนที่ผล BUY ออกมาว่า "มีแนวโน้มจะซื้อ"

| คำถาม | ตัวเลือก |
|---|---|
| ลักษณะการใช้รถ | ขับในเมืองเป็นหลัก / ขับนอกเมืองเป็นหลัก / ทั้งในและนอกเมือง |
| ความถี่ในการใช้รถ | เป็นครั้งคราว / 1–2 วัน/สัปดาห์ / 3–4 วัน/สัปดาห์ / 5–6 วัน/สัปดาห์ / ทุกวัน |
| ระยะทางต่อวัน | น้อยกว่า 10 / 10–30 / 31–50 / 51–70 / 71–90 / มากกว่า 90 กม. |
| รถที่เคยใช้ (เลือกได้หลายข้อ ไม่เลือกก็ได้) | สันดาป (ดีเซล/เบนซิน) / ไฮบริด / ไฟฟ้า |
| สิ่งที่ให้ความสำคัญ (เลือกได้หลายข้อ) | ราคารถ / ผ่อนชำระ / ค่าน้ำมัน / ค่าไฟฟ้า / ค่าซ่อมบำรุง / สมรรถนะ / ดีไซน์-รูปลักษณ์ / เทคโนโลยี / ความคุ้มค่า / การรับประกัน |
| "ประเภทพลังงานของรถยนต์มีความเหมาะสมกับการใช้งาน" | ให้คะแนน 1–5 (1 = ไม่เห็นด้วยอย่างยิ่ง, 5 = เห็นด้วยอย่างยิ่ง) |

⚠️ ข้อสุดท้าย**ห้ามเปลี่ยนถ้อยคำ** เพราะต้องตรงกับแบบสอบถาม แต่**ควรเพิ่มคำอธิบายใต้ข้อ** เพราะผู้ใช้งง เช่น
"คุณให้ความสำคัญแค่ไหนว่าชนิดพลังงานของรถ (น้ำมัน/ไฮบริด/ไฟฟ้า) ต้องเหมาะกับการใช้รถของคุณ"

### ตัวเลขและความซื่อตรง
- **ห้ามแต่งตัวเลข** ห้ามใส่รีวิวปลอม ยอดผู้ใช้ปลอม หรือโลโก้พาร์ทเนอร์ที่ไม่มีจริง
- ตัวเลขความแม่นยำมาจากระบบเท่านั้น
  - BUY ถูกประมาณ 65 จาก 100 คน ถ้าทายคำตอบที่พบบ่อยที่สุดจะถูก 58
  - FUEL ถูกประมาณ 66 จาก 100 คน ถ้าทายคำตอบที่พบบ่อยที่สุดจะถูก 35
- หน้าผลทั้งสองหน้า**ต้องมีกล่อง "ผลนี้เชื่อได้แค่ไหน"** ที่บอก 3 เรื่อง: ความแม่นยำ, ระบบดูจากคำถามข้อไหนบ้าง และ "ใช้เป็นข้อมูลประกอบ คนตัดสินใจคือคุณ"
- ผลต้องเป็น**คำแนะนำ ไม่ใช่คำตัดสิน** เช่น "คุณมีแนวโน้มจะซื้อรถ" ไม่ใช่ "ไม่แนะนำให้ซื้อ"
- ห้ามอธิบายผลด้วยเหตุผลที่ระบบไม่ได้ใช้ เช่น "เพราะคุณมีที่ชาร์จ" ทั้งที่ไม่ได้ถาม
- **หน้าผล FUEL ห้ามแสดง % ความเหมาะสม** ให้แสดงเป็นอันดับ 1-2-3 พร้อมเหตุผลภาษาไทยแทน

### ขั้นตอนการใช้งาน (ห้ามเปลี่ยน)
หน้าแรก → ล็อกอิน/สมัคร → ฟอร์ม BUY → ผล BUY → (ถ้ามีแนวโน้มซื้อ) ฟอร์ม FUEL → ผล FUEL → รุ่นรถที่แนะนำ
- **หน้าทำนายทุกหน้าต้องล็อกอิน** เพราะอยู่ในขอบเขตที่กรรมการอนุมัติแล้ว
- **หน้าภาพรวมข้อมูล (dashboard) เปิดได้โดยไม่ต้องล็อกอิน** และทุกคนเห็นเหมือนกัน ห้ามแสดงผลส่วนตัว
- มีหน้าแอดมินแยก (จัดการผู้ใช้และรายการรถ)

### ภาษาและการใช้งาน
- **ภาษาไทยทั้งหมด** ห้ามศัพท์อังกฤษบนหน้าเว็บ เช่น Dashboard, Binary, Model, Top 1, SVM, Data Mining
- **ฟอนต์ต้องรองรับภาษาไทย** สระและวรรณยุกต์ห้ามถูกตัด ระยะบรรทัดต้องพอสำหรับภาษาไทย
- ห้ามตัดคำกลางคำ (เคยเจอ "เชื้อ / เพลิง" ตกบรรทัด)
- ต้องใช้ได้ดีทั้งมือถือและคอมพิวเตอร์ ปุ่มกดบนมือถือต้องใหญ่พอ ตัวหนังสือห้ามเล็กกว่า 14px
- ต้องมีโหมดสว่างและโหมดมืด ข้อความต้องอ่านชัดทั้งสองโหมด
- ช่องที่กรอกผิดต้องใช้สีแจ้งเตือน ไม่ใช่สีหลักของเว็บ

## 3. สิ่งที่ทำให้เว็บเดิมดูเป็น AI (ห้ามทำซ้ำ)
- ทุกอย่างค่อย ๆ ลอยขึ้นมาทีละชิ้นตอนเลื่อนหน้า
- ไอคอนนำหน้าทุกหัวข้อและทุกปุ่ม รวมถึงไอคอนชิป "สมอง AI" บนปุ่มวิเคราะห์
- การ์ด 3 ใบเรียงกัน แต่ละใบมีไอคอน หัวข้อ และคำอธิบาย
- หน้าแรกเต็มจอ มีเงารถจาง ๆ และแถวตัวเลขโชว์
- ลำดับ 01 / 02 / 03
- ป้ายเล็ก ๆ รกหน้า เช่น "แนะนำอันดับ 1" "Top 1" หรือป้ายภาษาอังกฤษ
- กล่องตัวเลขที่ไม่มีประโยชน์กับผู้ใช้
- ปุ่มหรือตัวหนังสือไล่สีม่วง-ฟ้า
- คำโฆษณากว้าง ๆ เช่น "ตัดสินใจได้อย่างมั่นใจ"

## 3.5 กันไม่ให้ออกมาเหมือนเว็บ AI ทั่วไป

**ข้อทดสอบ:** ถ้าเอาดีไซน์นี้ไปใส่เว็บขายประกันหรือเว็บแอปอื่น แล้วใช้ได้เลยโดยไม่ต้องแก้ = **ยังไม่ผ่าน**
ดีไซน์ต้องมาจากตัวงานนี้ ได้แก่ ข้อมูลแบบสอบถามจริง การบอกความแม่นยำตามจริง และคนไทยที่กำลังตัดสินใจซื้อรถคันแรก

**ห้ามใช้ เว้นแต่มีเหตุผลเฉพาะของงานนี้** (เป็นค่าตั้งต้นที่ AI ชอบหยิบมาใช้):
- พื้นหลังสีครีมหรือขาวอมเหลือง
- คำเอียงตัวมีเชิงแทรกในหัวข้อ
- ป้ายตัวเล็กเหนือหัวข้อ เช่น "ขั้นตอนที่ 1" หรือ "ฟีเจอร์" ที่วางเหนือหัวข้อใหญ่ (**ห้ามเด็ดขาด** ให้หัวข้อสื่อสารเอง)
- ป้ายหรือตัวหนังสือแบบ monospace (ตัวพิมพ์ดีด) เพื่อให้ดูเทคนิค
- ปุ่มทรงแคปซูลโค้งมนสุด ๆ ทุกปุ่ม
- การ์ดขนาดเท่ากันเรียงเป็นตาราง แต่ละใบมีไอคอน หัวข้อ และข้อความ เป็นโครงหลักของหน้า
- การ์ดซ้อนการ์ด
- ตัวเลขใหญ่ ป้ายเล็ก และสถิติประกอบ เรียงเป็นแถวโชว์
- ตัวหนังสือไล่สี
- กระจกฝ้าหรือเบลอเพื่อความสวยอย่างเดียว
- เส้นสีหนาด้านซ้ายของการ์ดหรือกล่องแจ้งเตือน
- อิโมจิแทนไอคอน
- เลือกโหมดมืดหรือสว่างตามแฟชั่น (ให้เลือกจากสถานการณ์ใช้งานจริงแทน)
- ภาพเคลื่อนไหวแบบเดียวกันทุกส่วน (ถ้ามี ให้มีจุดเดียวที่ตั้งใจ)

**วิธีสั่งให้ได้ผล:** ถ้าผลที่ได้ยังเจอข้อไหนข้างบน หรือเจอสไตล์ตั้งต้นใหม่ที่ไม่ชอบ ให้**เพิ่มลงรายการนี้แล้วสั่งใหม่** อย่าสั่งแค่ว่า "ทำให้ไม่เหมือน AI"

**สิ่งที่ดีอยู่แล้ว ควรเก็บไว้:** หน้าภาพรวมข้อมูล (dashboard) ที่ตรงไปตรงมา มีจำนวนคนกำกับทุกกราฟ และมีคำเตือนว่าไม่ใช่ตัวแทนคนทั้งประเทศ
