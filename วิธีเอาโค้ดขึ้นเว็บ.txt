ทำไมต้องมี 3 ขั้น (ข้ามขั้นไหนก็ไม่ขึ้น)
--------------------------------------------------------
โค้ดต้องเดินทาง 3 ทอดกว่าจะถึงคนที่เปิดเว็บ:

   เครื่องเรา  --(1) push-->  GitHub  --(2) pull-->  PythonAnywhere  --(3) Reload--> เว็บจริง

ขั้นที่ 3 คือที่ลืมกันบ่อยที่สุด ไฟล์ใหม่ถึงเซิร์ฟเวอร์แล้วก็จริง
แต่โปรแกรมที่รันอยู่ยังถือโค้ดเก่าค้างในหน่วยความจำ จนกว่าจะสั่งให้มันเริ่มใหม่


ขั้นตอนเต็ม
--------------------------------------------------------
[1] บนเครื่องเรา (ให้ Claude ทำให้ได้ บอกว่า "push ขึ้น GitHub")

    cd C:\Users\click\Desktop\car-decision-app
    git add -A
    git commit -m "ข้อความบอกว่าแก้อะไร"
    git push origin main

[2] บน PythonAnywhere -> เมนู Consoles -> เปิด Bash console

    cd ~/-car-decision-app
    git pull

    ต้องเห็นบรรทัดแบบ  3304148..89947fe  main -> origin/main
    ถ้าขึ้น "Already up to date." แปลว่าไฟล์ถึงแล้ว ให้ข้ามไปขั้น 3

[3] บน PythonAnywhere -> แท็บ Web -> กดปุ่มเขียว "Reload r4tt4.pythonanywhere.com"

    กดแล้วดูบรรทัด "Last reloaded" ใต้ปุ่ม
    เวลาต้องเปลี่ยนเป็นตอนนี้ ถ้าไม่เปลี่ยน = ยังไม่ติด ให้กดใหม่


อาการเสีย -> วิธีแก้ (เรียงตามที่เจอบ่อย)
--------------------------------------------------------
อาการ: แก้โค้ดแล้ว แต่เปิดเว็บยังเป็นของเก่า

  วิธีหาสาเหตุ ให้พิมพ์คำสั่งนี้ใน Bash console ของ PythonAnywhere
  (คำสั่งเดียว ตอบได้เลยว่าปัญหาอยู่ทอดไหน)

    cd ~/-car-decision-app && git log --oneline -1 && grep -c "ข้อความที่เพิ่งแก้" car-dss/templates/ไฟล์ที่แก้.html

  อ่านผลแบบนี้:

  * commit ไม่ใช่ตัวล่าสุด
      -> ยังไม่ได้ pull หรือ pull ไม่ผ่าน  ->  ทำขั้น [2] ใหม่

  * commit ถูกแล้ว แต่ในไฟล์ยังมีข้อความเก่า
      -> pull ลงคนละโฟลเดอร์กับที่เว็บใช้
      -> เช็คว่าเว็บใช้โฟลเดอร์ไหนด้วย:
           cat /var/www/r4tt4_pythonanywhere_com_wsgi.py
         ดูบรรทัด project_home = '...'  ต้องเป็น /home/R4TT4/-car-decision-app/car-dss

  * commit ถูก + ไฟล์ใหม่แล้ว แต่เว็บยังเก่า   <-- เจอบ่อยที่สุด
      -> ยังไม่ได้ Reload (หรือกดแล้วไม่ติด)
      -> กดปุ่ม Reload ในแท็บ Web ให้ "Last reloaded" เปลี่ยนเวลา
      -> ถ้ากดแล้วยังไม่หาย สั่งรีสตาร์ทด้วยมือแทน:

           touch /var/www/r4tt4_pythonanywhere_com_wsgi.py

         (คำสั่งนี้แตะไฟล์ตั้งค่าให้ระบบรู้ว่ามีการเปลี่ยนแปลง แล้วมันจะรีสตาร์ทเว็บให้เอง)


อาการ: git pull ขึ้น error ว่ามีไฟล์แก้ค้างบนเซิร์ฟเวอร์

    git stash          # เก็บของที่แก้ค้างไว้ก่อน
    git pull
    (ปกติไม่ควรแก้ไฟล์บนเซิร์ฟเวอร์โดยตรง ให้แก้บนเครื่องแล้ว push เสมอ)

--------------------------------------------------------
บอกว่า "เช็คเว็บให้หน่อย" Claude เช็คได้เองจากนอกเครื่อง ว่าโค้ดขึ้นจริงไหม
แต่ Claude เข้าบัญชี PythonAnywhere ไม่ได้ ขั้น [2] กับ [3] ต้องทำเอง


เรื่องอื่นที่ควรรู้
--------------------------------------------------------
* ไฟล์โมเดล car-dss/models/*.pkl ต้องอยู่ใน git เสมอ ห้ามใส่ .gitignore
  เพราะเว็บอัปเดตด้วย git pull ถ้าไม่มีในgit เซิร์ฟเวอร์จะค้างโมเดลเก่าตลอดไป

* เซิร์ฟเวอร์ทดสอบบนเครื่อง (python app.py) ต่อ Firebase ตัวเดียวกับเว็บจริง
  ทดสอบกรอกฟอร์มบนเครื่อง = มีข้อมูลบันทึกลงฐานข้อมูลจริงด้วย
  ข้อมูลทดสอบจะมี user_id ขึ้นต้นว่า guest_ ถ้าอยากล้างให้ลบเฉพาะพวกนี้

* เปิดเว็บทดสอบบนเครื่อง: http://127.0.0.1:5000
  ถ้าจะให้ Claude กดทดสอบผ่าน Chrome ให้ใช้ http://192.168.1.100:5000 แทน
  (Chrome ที่ Claude คุมอยู่ เข้า 127.0.0.1 ของเครื่องเราไม่ได้)
