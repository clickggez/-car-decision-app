# CarDSS · คู่มือดีไซน์และการส่งต่อ

> ผู้ใช้ออกแบบ · นำเข้าโปรเจกต์ 30 ก.ย. 2569 · ✅ ส่วนที่ 5 ทำแล้ว: หน้าแรกอยู่ `car-dss/templates/home.html` (มีเมนู/ท้ายเว็บของตัวเอง ยังไม่ย้ายเข้า `base.html` เพราะหน้าอื่นยังเป็นสไตล์เดิม)

## 1. แนวคิด

**"พระราม 2 คืนฝนตก"** เว็บเล่าเรื่องผ่านสิ่งที่คนบางขุนเทียนเห็นทุกวัน ได้แก่ ป้ายทางหลวงสีเขียว หลักกิโลเมตร เทปกั้นงานก่อสร้าง น้ำท่วมขัง และรถติด

| หลัก | ความหมาย |
|---|---|
| ป้ายถนนคือภาษาหลัก | ปุ่ม การ์ด หัวข้อ หน้าตาเหมือนป้ายจราจรไทย ไม่ใช่การ์ดเว็บทั่วไป |
| ฝนนิ่ง น้ำขยับ | เส้นฝนเป็นภาพนิ่งทั้งหน้า ไม่ลายตา ของที่ขยับมีแค่น้ำ ใช้เฉพาะจุดสำคัญ |
| ส้มสำหรับกดเท่านั้น | สีส้มใช้กับปุ่มหลักและเทปกั้น ไม่ใช้ตกแต่ง |
| ภาษาคนทั่วไป | "รถไฟฟ้า / ไฮบริด / สันดาป" ก่อนตัวย่อ EV / HEV / ICE เสมอ |

ธีมเป็น **โหมดมืดอย่างเดียว** โดยตั้งใจ

### น้ำในส่วนหัวเรื่อง (`#water`)

- **หลักการ:** ผิวน้ำแบ่งเป็นคอลัมน์ละ 6px แต่ละคอลัมน์เป็นสปริง แล้วส่งแรงไปคอลัมน์ข้าง ๆ 4 รอบต่อเฟรม
- **ค่าที่ใช้:** `DEPTH=112` · `K=0.02` · `DAMP=0.012` · `SPREAD=0.25`
- **หินกิโล:** ลอยด้วยสปริงตามระดับน้ำ จมลงไป 30% ของความสูง (`DRAFT=0.3`) เอียงตามความชันของผิวน้ำ และโยกเบา ๆ ±3px
- **จังหวะน้ำ:** น้ำค่อย ๆ ขึ้นใน 5 วินาทีแรก มีหยดฝนตกกระทบทุก 0.25–0.95 วินาที และมีคลื่นใหญ่จากขอบทุก 3.5–6 วินาที
- **ประหยัดเครื่อง:** หยุดคำนวณเมื่อเลื่อนพ้นหน้าจอ (IntersectionObserver)

### คำถาม 3 ข้อ (`#route`)

คำถามคือ ระยะทางต่อวัน · ไปต่างจังหวัดบ่อยแค่ไหน · ชาร์จที่บ้านได้ไหม แต่ละคำตอบบวกคะแนนให้แต่ละประเภท ประเภทที่ได้คะแนนสูงสุดเป็นคำใบ้ (ถ้าเสมอกันเลือก ไฮบริด > ไฟฟ้า > สันดาป)

| คำตอบ | ไฟฟ้า | ไฮบริด | สันดาป |
|---|---|---|---|
| ขับ < 30 / 30–80 / > 80 กม. | 2 / 2 / 1 | 0 / 2 / 3 | 3 / 1 / 0 |
| แทบไม่ไป / เดือนละครั้ง / ทุกสัปดาห์ | 2 / 1 / −1 | 1 / 2 / 2 | 1 / 1 / 1 |
| ชาร์จได้ / ไม่แน่ใจ / ไม่ได้ | 3 / 0 / −3 | 0 / 1 / 1 | 0 / 1 / 2 |

- **ผลรวมทุกแบบของคำตอบ (27 แบบ):** ไฮบริด 15 · ไฟฟ้า 6 · สันดาป 6
- **เชื่อมกับส่วน 25 รุ่น:** คำใบ้ส่งต่อด้วย event `cardss:hint` ส่วน `#models` จะขึ้นป้าย "เข้ากับคุณ" บนประเภทนั้น
- ⚠️ **ชุดคำถามนี้เป็นตัวอย่าง** ต้องเปลี่ยนให้ตรงกับฟอร์ม `/predict/fuel` จริง และหน้าเว็บบอกผู้ใช้ไว้ว่า "ไม่ใช่ผลจากโมเดลพยากรณ์"

### รถหล่น (`#models`)

- **ไลบรารี:** Matter.js 0.19.0 จาก jsdelivr (`cdn.jsdelivr.net/npm/matter-js@0.19.0/build/matter.min.js` · เดิม cdnjs เปลี่ยนตามกฎ CDN 30 ก.ย. 2569)
- **ตัวรถ:** รถ 1 คัน = 1 รุ่น ขนาดยาว `L = clamp(104, W/8, 180)` px รูปทรงสำหรับชนกันใช้เส้นขอบ (convex hull) ของรูปจริงแต่ละคัน
- **น้ำ:** สูง `0.2 × L` คำนวณแบบเดียวกับส่วนหัวเรื่อง
  - แรงลอยตัว = 78% ของน้ำหนักรถ × สัดส่วนที่จม รถจึงค่อย ๆ จมลงพื้น
  - น้ำชะลอความเร็วรถ
  - รถหล่นลงน้ำเร็วจะมีหยดน้ำกระเซ็น
- **การลาก:** ลากด้วยเมาส์หรือนิ้ว แล้วมีป้ายชื่อรุ่นขึ้นมา บนมือถือ ถ้าเริ่มแตะที่ตัวรถจะลากรถ ถ้าเริ่มแตะที่ว่างจะเลื่อนหน้าเว็บ
- **เริ่มหล่นเมื่อ:** ส่วนนี้โผล่ในจอ 25%
- **ถ้ารูปรถโหลดไม่ทัน:** รอไม่เกิน 2.5 วินาที แล้วใช้รถวาดแทน

## 5. ส่งต่อ: ใส่หน้าแรกในเว็บ Flask จริง

> ส่วนนี้เขียนให้ Claude Code ทำตามได้ทีละขั้น ก่อนเริ่ม ให้ Claude Code อ่านโครงโปรเจกต์ (`app.py`, `templates/`, `static/`) ก่อน แล้วปรับชื่อไฟล์ตามของจริง

### 5.1 แยกไฟล์

| จาก `index.html` | ไปที่ |
|---|---|
| ทุกอย่างใน `<style>` | `static/css/cardss.css` |
| สคริปต์รถหล่น (`<script>` ก้อนแรก เริ่มที่ `const { Engine, Bodies...`) | `static/js/cardss-models.js` |
| สคริปต์ฝน น้ำ เมนู และคำถาม (`<script>` ก้อนหลัง) | `static/js/cardss-home.js` |
| `cars/*.webp` (25 ไฟล์ รวม ~720 KB) | `static/img/cars/` |
| เมนูบน + ท้ายเว็บ + ชั้นฝน `.rain-layer` | `templates/base.html` ใช้ร่วมทุกหน้า |
| เนื้อหาส่วน 2–8 | `templates/index.html` ที่ `{% extends "base.html" %}` |

**ลำดับ script (ท้าย `home.html`):** `matter.min.js` (jsdelivr) → `cardss-models.js` → `cardss-home.js` ใส่ท้าย `<body>`

### 5.2 เปลี่ยนลิงก์และพาธ

- **ลิงก์:** แทน `https://r4tt4.pythonanywhere.com/...` ด้วย `{{ url_for('...') }}` ตามชื่อ route จริง (หน้าแรก, `predict/buy`, `predict/fuel`, `dashboard`, `login`)
- **รูปรถ:** ในตัวแปร `PHOTOS` ของ `cardss-models.js` ฟิลด์ `src` เป็นพาธ `cars/xxx.webp` ให้เปลี่ยนเป็น `/static/img/cars/xxx.webp` หรือส่งพาธมาจาก template:
  ```html
  <script>window.CARDSS_IMG = "{{ url_for('static', filename='img/cars/') }}";</script>
  ```
  แล้วใน JS ใช้ `CARDSS_IMG + slug + '.webp'`

### 5.3 ข้อมูลจากฐานข้อมูล (ถ้าต้องการ)

| ตรงไหนในหน้า | ค่าตอนนี้ | ควรมาจาก |
|---|---|---|
| หินกิโล "ข้อมูลตัวอย่าง" | 500 | จำนวนแถวในชุดข้อมูล |
| หินกิโล "รุ่นรถในระบบ" | 25 | จำนวนรุ่นในตารางรถ |
| หินกิโล "โมเดลพยากรณ์" | 2 | ค่าคงที่ |
| ป้ายประเภท 12 / 8 / 5 รุ่น และ `DATA` ใน `cardss-models.js` | เขียนไว้ในโค้ด | รายชื่อรุ่นแยกตามประเภท |
| หัวข้อ "25 รุ่น แบ่งตามเชื้อเพลิง" | 25 | จำนวนรุ่นรวม |

ส่งรายชื่อรุ่นเป็น JSON จาก Flask:

```html
<script>window.CARDSS_MODELS = {{ cars_by_type | tojson }};</script>
```

ถ้ามีตัวแปรนี้ หน้าเว็บจะใช้รายชื่อนี้แทนรายชื่อในโค้ด และอัปเดตจำนวนบนป้ายประเภทให้เอง รูปแบบข้อมูล `{ "ev": [["Tesla","Model 3","sedan"], ...], "hev": [...], "ice": [...] }` ถ้ามีรุ่นใหม่ที่ยังไม่มีรูป ระบบจะใช้รถวาดแทนอัตโนมัติ

## 6. เรื่องที่ยังค้าง

1. **คำถาม 3 ข้อ:** ยังไม่ตรงกับฟอร์ม `/predict/fuel` จริง (ฟอร์มต้องล็อกอินก่อน จึงยังไม่ได้ดู)
2. **ปุ่มเข้าระบบทุกปุ่มเจอหน้าล็อกอินก่อน:** ควรบอกไว้ข้างปุ่ม หรือเปิดให้ลองโดยไม่ต้องล็อกอิน
3. ✅ **ระยะทางบนป้ายเขียว ตรวจแล้ว 30 ก.ย. 2569** (ผู้ใช้วัดด้วย Google Maps เริ่มจากเซ็นทรัล พระราม 2): มหาชัย 28–29 · บางขุนเทียน-ชายทะเล 20–21 (เดิมเขียน "ถนน พระราม 2" แก้แล้ว) · ดาวคะนอง 9–10 กม. ~~(28–29 / 20–21 / 9–10 กม.)~~ และ **"ใช้เวลากรอกประมาณ 2 นาที":** ยังไม่ได้ตรวจกับข้อมูลจริง
4. **รูปรถ 25 รุ่น:** ผู้ใช้หามาเอง ถ้าเผยแพร่จริงต้องเช็กสิทธิ์การใช้และใส่เครดิตแหล่งที่มา
5. **หน้าอื่นยังไม่ได้ออกแบบ:** ฟอร์มพยากรณ์ 2 หน้า หน้าผลลัพธ์ Dashboard และล็อกอิน ให้ใช้ส่วนที่ 2–3 ของเอกสารนี้
6. **ยังไม่ได้ทดสอบ:** บนมือถือจริง และบนเครื่องสเปกต่ำ (มีน้ำขยับ 2 จุด)
