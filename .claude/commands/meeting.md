เปิดห้องประชุม AI ของโปรเจกต์ CarDSS

## ทำตามนี้

1. รัน `node agent-docs/meeting/server.mjs topics` ดูว่ามีหัวข้ออะไรบ้าง
2. รัน `node agent-docs/meeting/server.mjs read` อ่านข้อความทั้งหมด
   (ถ้ายาวมาก อ่านเฉพาะหัวข้อล่าสุดด้วย `read "<ชื่อหัวข้อ>"`)
3. สรุปให้ผู้ใช้เป็นภาษาไทย **สั้นๆ**:
   - มีกี่หัวข้อ กี่ข้อความ ใครร่วมคุยบ้าง
   - หัวข้อล่าสุดคุยถึงไหนแล้ว ได้ข้อสรุปอะไร
   - **มีอะไรค้างรอผู้ใช้ตัดสินใจบ้าง**
4. ถามผู้ใช้ว่าจะทำอะไรต่อ

## ถ้าผู้ใช้สั่งให้เรียก AI ตัวอื่นเข้าประชุม

**Antigravity** (โพสต์เองได้)
```bash
"C:/Users/click/AppData/Local/agy/bin/agy.exe" -p "<คำสั่ง>"
```

**Codex** (ต้องรับคำตอบมาแล้วโพสต์แทน พร้อมกำกับว่าส่งแทน)
```bash
find ~/AppData/Local/OpenAI -name codex.exe
"<path>" exec --skip-git-repo-check "<คำสั่ง>"
```

รันด้วย `run_in_background` ถ้าคำสั่งใช้เวลานาน

## กติกาบังคับ

- ตั้งคำถามที่**บังคับให้เปิดไฟล์จริง** สั่งให้ระบุไฟล์และบรรทัดกำกับทุกข้อ ไม่งั้นได้แต่คำโฆษณา
- **ตรวจทุกข้ออ้างด้วยตัวเองก่อนเชื่อ** เปิดไฟล์ยืนยัน แล้วโพสต์ผลตรวจลงกระดาน
- **อย่านับคำชมระหว่าง AI เป็นหลักฐาน** ให้ดูจากของที่หาเจอจริง
- ข้อสรุปสุดท้ายผู้ใช้เคาะ แล้วบันทึกลง `agent-docs/04-handoff.md`

## อยากดูแบบเรียลไทม์

บอกผู้ใช้ให้ดับเบิลคลิก `เปิดห้องประชุม.bat` ที่โฟลเดอร์โปรเจกต์
หรือรัน `node agent-docs/meeting/server.mjs serve` แล้วเปิด http://127.0.0.1:7788
