# ข้อเสนอคำถามแบบสอบถามใหม่ — เพิ่ม effect size ให้โมเดล BUY/FUEL

**วันที่:** 2026-07-30
**เหตุผลที่ต้องทำ:** พิสูจน์แล้วด้วย 3 เทคนิคทางสถิติอิสระกัน (Chi-square, ANOVA, Mutual Information+permutation) ว่าคำถามชุดปัจจุบัน (demographic + 7P Likert ทั่วไป) มีความสัมพันธ์กับพฤติกรรมซื้อ/เลือกเชื้อเพลิงอ่อนเกินกว่าจะดัน accuracy ขึ้นได้อีกด้วยวิธีการเทรน — ทางเดียวที่มีโอกาสจริงคือคำถามที่มี effect size แรงกว่าเดิม

## ทำไมคำถามเดิมถึงมีสัญญาณอ่อน (สาเหตุที่วินิจฉัยได้จากข้อมูล)

1. **Demographic ล้วนๆ (อายุ, เพศ, อาชีพ, รายได้) เป็น proxy ทางอ้อมของพฤติกรรม** — งานวิจัยพฤติกรรมผู้บริโภค (Theory of Planned Behavior, TPB) พบว่า demographic ทำนายพฤติกรรมได้อ่อนกว่า "เจตนา/ทัศนคติที่วัดตรง" มาก
2. **7P Likert เดิมเป็นคำถามความเหมาะสมทั่วไป ("ราคาเหมาะสมไหม") ไม่ใช่คำถามเจาะจงพฤติกรรม** — คำตอบกระจุกที่ 4-5 แทบทุกคน (variance ต่ำ) ตามที่บันทึกไว้ใน Known Issue เดิม
3. **ไม่มีคำถาม "เจตนาซื้อ" ตรงๆ** — งานวิจัย purchase-intention เกือบทั้งหมดใช้ direct intention scale เป็นตัวทำนายหลัก ไม่ใช่อนุมานจาก field อื่น

## คำถามใหม่ที่เสนอ — สำหรับ predict_buy (อิงกรอบ Theory of Planned Behavior)

| Construct | ตัวอย่างคำถาม (Likert 5-7 ระดับ) | เหตุผลที่คาดว่า effect size แรงกว่าเดิม |
|---|---|---|
| **เจตนาซื้อโดยตรง (Purchase Intention)** | "ท่านตั้งใจจะซื้อรถยนต์ภายใน 6 เดือนข้างหน้าหรือไม่" (แน่นอนไม่ซื้อ...แน่นอนจะซื้อ) | เป็น proxy ที่ตรงกับ label มากที่สุด งานวิจัย TPB พบว่า intention ทำนาย actual behavior ได้ r=0.4-0.6 (สูงกว่า demographic มาก) |
| **ทัศนคติ (Attitude)** | "การมีรถยนต์เป็นของตัวเองเป็นเรื่องสำคัญ/จำเป็นสำหรับท่าน" | ทัศนคติเชิงบวกต่อการเป็นเจ้าของรถสัมพันธ์กับการตัดสินใจซื้อโดยตรง |
| **การคล้อยตามกลุ่มอ้างอิง (Subjective Norm)** | "คนใกล้ชิด (ครอบครัว/เพื่อนร่วมงาน) คิดว่าท่านควรมีรถยนต์เป็นของตัวเอง" | แรงกดดันทางสังคมเป็นปัจจัยที่ TPB literature ยืนยันว่ามีน้ำหนักจริง |
| **การรับรู้ความสามารถควบคุม (Perceived Behavioral Control)** | "ท่านมีความพร้อมทางการเงินที่จะซื้อรถยนต์ตอนนี้" (แยกจากคำถามรายได้/งบเดิมที่เป็นแค่ bracket กว้างๆ) | วัดความพร้อมจริงเจาะจงกว่า income bracket |
| **ตัวกระตุ้นเชิงสถานการณ์ (Situational trigger)** | "มีเหตุการณ์ในชีวิตล่าสุด (เปลี่ยนงาน/ย้ายที่อยู่/มีบุตร) ที่ทำให้ท่านต้องการรถยนต์หรือไม่" (ใช่/ไม่ใช่) | Life-event เป็นตัวกระตุ้นการซื้อรถที่งานวิจัยยืนยันชัดเจนกว่าคุณสมบัติคงที่ (static demographic) |

## คำถามใหม่ที่เสนอ — สำหรับ predict_fuel (อิงงานวิจัย EV Adoption)

| Construct | ตัวอย่างคำถาม | เหตุผล |
|---|---|---|
| **ที่ชาร์จที่บ้าน/ที่ทำงาน (Charging access)** | "ที่พักอาศัย/ที่ทำงานของท่านมีจุดชาร์จไฟฟ้าหรือติดตั้งได้หรือไม่" (มี/ติดตั้งได้/ไม่มีและติดตั้งไม่ได้) | งานวิจัย EV adoption ทั่วโลกชี้ว่าเป็น**ปัจจัยทำนายอันดับ 1** ของการเลือก EV — แรงกว่า Likert "ความกังวลเรื่องพลังงาน" มาก และปัจจุบันแบบสอบถามไม่มีคำถามนี้เลย |
| **ประสบการณ์ตรง (Prior exposure)** | "ท่านเคยทดลองขับ/นั่งรถ EV หรือ Hybrid มาก่อนหรือไม่" (ใช่/ไม่ใช่) | ประสบการณ์ตรงลด range anxiety และเปลี่ยนทัศนคติได้มากกว่าข้อมูลที่ได้ยินมา |
| **Range anxiety โดยตรง** | "ท่านกังวลว่าแบตเตอรี่จะหมดระหว่างทางหรือไม่" (ไม่กังวลเลย...กังวลมาก) — แยกจาก "ระยะทางที่ขับ" ที่เป็นแค่ fact ไม่ใช่ทัศนคติ | วัดทัศนคติที่แท้จริงแทนการอนุมานจากระยะทางเฉยๆ |
| **ความรู้เรื่องต้นทุนรวม (TCO awareness)** | "ท่านทราบหรือไม่ว่าค่าไฟชาร์จ EV ต่อเดือนถูกกว่าค่าน้ำมันโดยเฉลี่ยเท่าไร" (ทราบ/ไม่ทราบ + ประมาณการ) | ความรู้เรื่อง TCO สัมพันธ์กับการตัดสินใจเลือก EV ในงานวิจัยหลายชิ้น ต่างจาก "ความกังวลค่าไฟ" ที่เป็น attitude กว้างๆ |
| **แรงจูงใจสิ่งแวดล้อม (Environmental concern, เจาะจงกว่าเดิม)** | ใช้ New Ecological Paradigm (NEP) scale แบบย่อ (3-5 ข้อมาตรฐาน) แทน Likert เดี่ยวที่คลุมเครือ | Scale มาตรฐานมี construct validity สูงกว่าคำถามเดี่ยวที่สร้างขึ้นเอง |
| **สิทธิประโยชน์ภาครัฐ (Incentive awareness)** | "ท่านทราบเรื่องสิทธิประโยชน์ทางภาษี/เงินอุดหนุนรถ EV หรือไม่" | ปัจจัยเชิงนโยบายที่มีผลจริงต่อการตัดสินใจ แต่แบบสอบถามเดิมไม่ได้ถาม |

## ข้อควรระวังเชิงวิธีวิจัย (ป้องกันปัญหาเดิมซ้ำ)

1. **เพิ่มจำนวนระดับ Likert เป็น 7 ระดับ** (จาก 5 เดิม) และใช้ anchor คำอธิบายชัดเจนทุกระดับ — ลด ceiling effect ที่ทำให้คำตอบกระจุกที่ 4-5 เหมือนชุดเดิม
2. **ผสมคำถามเชิงลบ (reverse-worded) บางข้อ** กันตอบไปทางเดียวโดยไม่อ่าน (acquiescence bias)
3. **เก็บ n ให้พอสำหรับ FUEL model โดยเฉพาะ** — ปัจจุบัน ICE มีแค่ 105 ตัวอย่าง เทียบ EV/Hybrid ~144-148 ควรเก็บเพิ่มเฉพาะกลุ่ม ICE ให้สมดุลกว่านี้ (คำถามใหม่ก็ต้องมีสัดส่วนกลุ่มที่ตอบครบทุกกลุ่มเชื้อเพลิง)
4. **Pilot test คำถามใหม่กับกลุ่มเล็ก (~30-50 คน) ก่อนเก็บเต็มจำนวน** เพื่อเช็ค variance ว่าคำถามใหม่แยกแยะคนได้จริง (ไม่กระจุกเหมือนเดิม) ก่อนเสียเวลาเก็บเต็มรอบ
5. **เก็บคำถามเดิมไว้ด้วย** (ไม่ลบ) เพื่อเปรียบเทียบว่าฟีเจอร์ใหม่เพิ่ม predictive power จริงหรือไม่ (ablation-style comparison ในบทวิเคราะห์)

## สิ่งที่ต้องทำถ้าอาจารย์อนุมัติแนวทางนี้

1. เพิ่มคำถามใหม่ในแบบฟอร์ม Google Form (ไม่แก้คำถามเดิม แค่เพิ่มต่อท้าย)
2. Pilot test ~30-50 คนก่อน เช็ค variance ของคำถามใหม่
3. เก็บข้อมูลเต็มรอบ (เป้าเน้นกลุ่ม ICE ให้สมดุลขึ้นสำหรับ FUEL model)
4. เพิ่มฟิลด์ใหม่ใน `feature_encoding.py`/`train_models.py` (Claude Code ทำได้ทันทีเมื่อมีข้อมูล ไม่ต้องรอ) — **หมายเหตุ: ขั้นตอนนี้จะถือเป็นการเปลี่ยน signature ของ `predict_buy()`/`predict_fuel()` ซึ่งปกติเป็นข้อห้ามของโปรเจกต์ (`01-architecture.md`) แต่ได้รับอนุมัติแล้วในกรณีนี้เพราะเป็นการขยาย scope ตามคำสั่งอาจารย์**
